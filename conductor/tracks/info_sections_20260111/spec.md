# Spec: Core Information Sections (Programs, Coaches, and About)

## Overview
This track focuses on building the core content areas of the IRON & GLOVES website. These sections provide depth to the brand story, detail the training offerings, and introduce the expert staff. All sections must adhere to the "Modern Stealth" aesthetic and utilize "Impactful & Kinetic" motion patterns.

## Requirements
- **About Section:**
    - High-impact storytelling layout using "Punchy & Minimalist" prose.
    - GSAP scroll-triggered text reveals and parallax image/texture elements.
- **Training Programs Section:**
    - Interactive cards for each program (e.g., Boxfit, Technical Boxing).
    - Use `PremiumCard` component with enhanced hover states.
    - Clear "Intensity Indicators" for each program.
- **Coaches Section:**
    - A kinetic grid or carousel of coaches.
    - Image-reveal animations using GSAP.
    - Bio popups or expansion on interaction.
- **Consistency:**
    - Shared motion patterns for section reveals (staggered entries).
    - Strict adherence to the brand color palette and typography.

## Success Criteria
- All three sections are fully responsive.
- GSAP animations trigger reliably on scroll and feel snappy (<0.6s).
- Text and imagery follow the "Abstract & Graphic" guidelines.
- Navigation links in the Header correctly anchor to these new sections.
