# Spec: Core Visual Identity & Hero Section

## Overview
This track establishes the foundation of the IRON & GLOVES digital presence. It focuses on the high-impact visual system, the primary layout, and the cinematic Hero section that defines the brand's "Modern Stealth" aesthetic and "Impactful & Kinetic" motion strategy.

## Requirements
- **Visual System:** Implement the Matte Black, Slate Grey, and Neon Volt color palette.
- **Typography:** Set up the bold sans-serif typographic hierarchy.
- **Layout:** Create the responsive shell, including the "Smart" navigation bar.
- **Hero Section:**
    - High-contrast background (Abstract/Graphic texture).
    - Large, kinetic typography for the headline "IRON & GLOVES".
    - GSAP-powered entrance animations for text and primary CTA.
    - Responsive design ensuring the "Modern Stealth" feel on mobile.
- **Navigation:** Primary "Explore Programs" CTA and main menu links.

## Success Criteria
- The Hero section performs smooth, high-energy entrance animations on load.
- The visual system strictly follows the "Modern Stealth" palette.
- The layout is fully responsive and maintains a premium feel on mobile.
- Page load performance is optimized for high-impact assets.
